最后 10 篇的最新互动快照：`readNum` 10/10、`likeNum` 10/10、`commentNum` 10/10 有值；`shareNum` 0/10 有值，按缺失记录，不写成 0。`oldLikeNum` 与可见评论明细尚未通过验收。读取量是采集时快照。该轮未观察到微信退出登录；不能据此保证更长批次不会发生。

采集路径：Mac 微信可见窗口 → Vision OCR 卡片 → Quartz 点击/滚动 → 微信菜单复制真实 URL → 复制渲染正文 → 页尾账号核对 → SQLite 快照及缺失账本。每篇关闭后重新 OCR 主页卡片，避免沿用旧坐标。跨运行保存的视口位置提示不再被当成链接身份；复制链接前还验证菜单属于目标文章标签。

- DeepSeek/豆包适配器有本地自动测试；本次实机批次未启用模型，因此不构成两家模型 API 的实机验收。

# Mac 源码体验包

此包用于 Apple Silicon（M 系列芯片）Mac。包含可双击的安装和启动入口、采集程序及固定依赖清单。它是联网安装的源码体验包，不是已签名的 `.app` 或离线 DMG；批量读取是否稳定，以仓库中的实机验收记录为准。

## 给使用者

1. 解压 `gzh-information-…-macos-arm64-source.zip`，把整个文件夹放到「文稿」等固定位置。
2. 双击文件夹内的 `安装.command`。首次会下载 uv、Python 3.12 和 Mac 依赖，需要联网。看到「安装完成」后按任意键关闭。
3. 双击 `启动.command`，浏览器会打开本机中文向导 `http://127.0.0.1:8765`。读取期间保留终端窗口。
4. 在微信中打开目标公众号主页，按向导填写文章链接、账号名称、输出目录与本轮篇数。首次需在系统设置的「隐私与安全性」中给实际启动的终端程序授予辅助功能和屏幕录制权限；授予后退出并重新启动终端。
5. 数据保存在你选的输出目录，后续使用相同目录继续。请勿把数据文件夹或模型密钥加入 GitHub。

若 macOS 拦截双击脚本，可按系统提示从「隐私与安全性」中允许你已核实来源的脚本；本包不会自动关闭系统安全设置。安装失败会保留窗口与错误；再次双击安装可修复缺失依赖。安装后启动直接使用本文件夹的 Python，因此不依赖 Finder 能否找到 uv。

旧服务仍在运行时，不要重复启动第二个服务；使用已经打开的界面，或先在旧终端按 Control-C。安装完成后不要单独移动 `.venv`，移动整个文件夹后请重新运行安装。

## 给维护者：生成发布包

在仓库内运行（Python 3.12 或更新版本）：

```sh
python3 scripts/package_mac.py
```

如果系统 Python 太旧，可使用项目已有环境：

```sh
.venv/bin/python scripts/package_mac.py
```

生成 `dist/gzh-information-<版本>-macos-arm64-source.zip` 与相邻 `.zip.sha256`。`dist/` 已被 Git 忽略。解压后 `PACKAGE-MANIFEST.json` 列出每个交付文件的 SHA-256；同一组源文件重复打包得到相同字节。

打包采用白名单：程序 Python 源码、两个启动脚本、README、MIT 许可、依赖清单、README 链接的通用说明（包括 Agent 起步说明）与验收记录，以及打包脚本。不会包含个人交接笔记、`.git`、`.venv`、原始正文、数据库、导出、日志、代理状态、运行时目录、Cookie 文件或凭据文件。打包前也检测常见明文密钥格式，命中时停止。源码修改应先通过适用测试和人工审阅；格式检测不等于能识别所有未知形式的密钥。

验证源码包包含正确权限，可在 macOS 使用归档实用工具解压，或用系统 `ditto -x -k`；两个 `.command` 在 ZIP 中带有 `0755` 权限。将包解压到独立临时目录验证安装，不要覆盖正在采集的工作目录。
